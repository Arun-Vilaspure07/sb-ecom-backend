# sb-ecom-backend

Spring Boot backend service for an e-commerce platform.

## Tech Stack
- Java 17
- Spring Boot
- Maven
- Spring Data JPA
- SonarQube + JaCoCo
- Docker
- GitHub Actions (CI)

## Features
- Product & Category management
- Caching
- Pagination & filtering
- DTO-based architecture
- Quality Gate enforcement

## Build & Run
```bash
mvn clean verify
